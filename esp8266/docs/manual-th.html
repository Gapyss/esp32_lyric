1อัปเดตเฟิร์มแวร์

อัปเดตผ่าน WiFi ได้เลย ไม่ต้องต่อสาย USB

ถ้าตอนนี้จอยังต่อ WiFi ไม่ได้เลย (เช่น WiFi ที่ทำงาน) ให้ต่อจอกับ WiFi บ้าน หรือ Hotspot จากมือถือ/คอมไปก่อน (ดูวิธีที่ขั้นที่ 2) อัปเดตให้เสร็จ แล้วค่อยเปลี่ยนไปใช้ WiFi ที่ทำงาน
  1. ดู IP address ที่หน้าจอ Clawdmeter เช่น 192.168.1.35
  2. ถ้าเปิดโปรแกรมเนื้อเพลงค้างไว้ ให้ปิดก่อน (ดูวิธีปิดที่ขั้นที่ 3) และปิดแท็บหน้าตั้งค่าของจอที่เปิดค้างไว้
  3. เปิดเบราว์เซอร์บนคอม ไปที่ 
    http://clawdmeter.local/update
    ถ้าเปิดไม่ขึ้น ให้ใช้ IP จากข้อ 1 แทน เช่น http://192.168.1.35/update
  4. หน้าเว็บจะขึ้นหัวข้อ firmware update พร้อมเวอร์ชันปัจจุบัน กด Choose File แล้วเลือกไฟล์ clawdmeter_esp8266.ino.bin
  5. กด update firmware แล้วรอ ห้ามถอดปลั๊ก ประมาณ 30 วินาที
  6. จอจะรีสตาร์ตเองและกลับมาแสดง IP อีกครั้ง ถ้าเบราว์เซอร์ค้าง ให้รอ 20 วินาทีแล้วเปิด http://clawdmeter.local ใหม่
เช็กว่าอัปเดตสำเร็จหรือยัง เปิด http://clawdmeter.local/update อีกครั้ง เลขเวอร์ชันข้างหัวข้อต้องเป็น 1.1.0 หรือใหม่กว่า

2ต่อ WiFi

ทำครั้งแรกครั้งเดียว หรือเมื่อต้องการย้ายไปใช้ WiFi อื่น

จะเข้าโหมดตั้งค่า WiFi ได้อย่างไร

  • ครั้งแรก หรือจอหา WiFi เดิมไม่เจอ: จอจะเข้าโหมดตั้งค่าเอง
  • ต้องการเปลี่ยน WiFi: เปิด http://clawdmeter.local แล้วกด change wifi

เมื่ออยู่ในโหมดตั้งค่า หน้าจอจะขึ้นแบบนี้

wifi setup

join this hotspot from a phone
Clawdmeter-setup

a setup page opens by itself
if not, browse to
192.168.4.1
  1. เอามือถือต่อ WiFi ชื่อ Clawdmeter-setup
  2. หน้าตั้งค่าจะเด้งขึ้นมาเอง ถ้าไม่เด้ง ให้เปิดเบราว์เซอร์ไปที่ 192.168.4.1
  3. กด Configure WiFi แล้วเลือกชื่อ WiFi ของคุณ
  4. ใส่รหัสผ่าน แล้วดูช่อง Username
    • WiFi บ้านทั่วไป: ปล่อยช่อง Username ว่างไว้
    • WiFi ที่ทำงานที่ถามทั้ง username และ password ตอนต่อ (802.1X / WPA2-Enterprise / PEAP): ใส่ username และ password แบบเดียวกับที่ใช้ต่อจากมือถือ
  5. กด Save แล้วรอจนจอแสดง IP address ใหม่ (WiFi ที่ทำงานอาจใช้เวลาถึง 30 วินาที)
เรื่องที่ควรรู้ถ้าใช้ WiFi ที่ทำงาน
  • ถ้าต่อ WiFi ได้ก่อนแล้วค่อยเด้งหน้าเว็บให้ login แบบนี้ไม่ใช่ 802.1X จอกรอกหน้านั้นให้ไม่ได้ แนะนำให้ใช้ Hotspot จากคอมแทน (ดูหัวข้อแก้ปัญหา)
  • รหัสผ่าน WiFi จะถูกเก็บไว้ในตัวจอ ถ้าเป็นไปได้ ให้ขอบัญชีสำหรับอุปกรณ์จากฝ่าย IT แทนการใช้บัญชีส่วนตัว
  • WiFi ที่ต้องใช้ใบรับรอง (certificate) ของเครื่องยังใช้ไม่ได้

3เชื่อมต่อเนื้อเพลง

คอมทำหน้าที่วาดเนื้อเพลงแล้วส่งไปที่จอ ต้องเปิดโปรแกรมนี้ทุกครั้งที่อยากให้จอแสดงเนื้อเพลง

ติดตั้งครั้งแรก (ทำครั้งเดียว)

  1. เปิดแอป Terminal (กด ⌘ + Space แล้วพิมพ์ Terminal)
  2. พิมพ์ cd ตามด้วยเว้นวรรค แล้วลากโฟลเดอร์โปรแกรมมาวางในหน้าต่าง Terminal กด Enter
  3. ติดตั้งส่วนที่ใช้วาดตัวอักษร 
    python3 -m pip install --user pyobjc-framework-CoreText pyobjc-framework-Quartz
    ถ้าเครื่องถามให้ติดตั้ง Command Line Tools ให้กดติดตั้ง แล้วรันคำสั่งนี้ซ้ำอีกครั้ง

เปิดโปรแกรมเนื้อเพลง (ทุกครั้งที่ใช้)

  1. ใน Terminal ให้เข้าโฟลเดอร์โปรแกรมเหมือนข้อ 2 ด้านบน
  2. พิมพ์ 
    esp8266/tools/lyrics.sh
  3. รอประมาณ 10 วินาที ถ้าขึ้น lyrics are on the panel. แปลว่าเชื่อมสำเร็จ ถ้าไม่ขึ้น โปรแกรมจะบอกว่าติดตรงไหน

ติดตั้งครั้งแรก (ทำครั้งเดียว)

  1. ติดตั้ง Python 3.10 ขึ้นไปจาก python.org ตอนติดตั้งต้องติ๊ก Add python.exe to PATH
  2. เปิดโฟลเดอร์โปรแกรมใน File Explorer คลิกที่แถบที่อยู่ด้านบน พิมพ์ powershell แล้วกด Enter
  3. ในหน้าต่าง PowerShell พิมพ์ 
    py -3 -m pip install -r esp8266\daemon\requirements-windows.txt
  4. ตั้งค่า WiFi ที่ใช้เป็น Private network: Settings → Network & internet → Wi-Fi → เลือก WiFi ที่ต่ออยู่ → Network profile type → Private

เปิดโปรแกรมเนื้อเพลง (ทุกครั้งที่ใช้)

  1. เปิด PowerShell ในโฟลเดอร์โปรแกรมเหมือนข้อ 2 ด้านบน
  2. พิมพ์ 
    powershell -ExecutionPolicy Bypass -File esp8266\tools\lyrics.ps1
  3. ครั้งแรก Windows จะถามเรื่อง Firewall ให้กด Allow สำหรับ Private networks
  4. รอประมาณ 10 วินาที โปรแกรมจะบอกว่าเชื่อมกับจอสำเร็จหรือติดตรงไหน

ติดตั้งส่วนขยายในเบราว์เซอร์ (ทำครั้งเดียว)

  1. เปิด Chrome แล้วพิมพ์ chrome://extensions ในช่องที่อยู่ (Edge ใช้ edge://extensions)
  2. เปิดสวิตช์ Developer mode ที่มุมขวาบน
  3. กด Load unpacked แล้วเลือกโฟลเดอร์ esp8266/browser_extension ในโฟลเดอร์โปรแกรม

เริ่มฟังเพลง

  1. เปิด music.youtube.com ใน Chrome หรือ Edge ตัวเดียวกับที่ติดตั้งส่วนขยาย
  2. เปิดเพลง ภายในไม่กี่วินาทีเนื้อเพลงจะขึ้นที่จอ

ปิดโปรแกรมเนื้อเพลง

Mac: esp8266/tools/lyrics.sh stop
Windows: powershell -ExecutionPolicy Bypass -File esp8266\tools\lyrics.ps1 stop

ถ้าไม่แน่ใจว่าตอนนี้ทำงานอยู่หรือเปล่า ให้ใช้ status แทน stop โปรแกรมจะบอกสถานะของทั้งคอมและจอ

แก้ปัญหา

ดูจากข้อความบนจอ แล้วทำตามช่องขวา

จอแสดงหมายความว่าวิธีแก้
Clawdmeter-setup จอต่อ WiFi ที่บันทึกไว้ไม่ได้ ตั้งค่า WiFi ใหม่ตามขั้นที่ 2 และเช็กว่าเป็น WiFi 2.4 GHz รหัสผ่านถูกต้อง ถ้าเป็น WiFi ที่ทำงานต้องกรอก Username ด้วย
waiting for lyrics จอยังไม่เจอคอม หรือยังไม่ได้เปิดเพลง เปิดโปรแกรมเนื้อเพลง (ขั้นที่ 3) แล้วเปิดเพลงใน YouTube Music จากนั้นรัน status ดูว่าติดตรงไหน
reaching the lyrics daemon… จอเจอคอมแล้ว แต่ต่อเข้าไม่ได้ Windows: อนุญาต Firewall และตั้ง WiFi เป็น Private ส่วน Mac: กด Allow ถ้าเครื่องถามเรื่องการเชื่อมต่อเข้า
wifi lost จอหลุดจาก WiFi รอสักครู่ จอจะต่อใหม่เอง ถ้าเกิน 10 นาทีจะรีสตาร์ตเอง

เปิด clawdmeter.local ไม่ขึ้น

ให้ใช้ IP ที่จอแสดงแทนทุกที่ ส่วนโปรแกรมเนื้อเพลง ให้เติม IP ต่อท้ายคำสั่งเปิด เช่น

esp8266/tools/lyrics.sh start --announce-url http://192.168.1.35

ใช้ WiFi ที่ทำงานแล้วจอขึ้น IP แต่เนื้อเพลงไม่มาเลย

WiFi องค์กรหลายแห่งไม่ให้อุปกรณ์คุยกันเอง จึงไม่เกี่ยวกับตัวจอ มีทางแก้ 2 ทาง

  • ใช้ Hotspot จากคอม (แนะนำ ทำได้เองทันที): Mac ใช้ System Settings → General → Sharing → Internet Sharing ส่วน Windows ใช้ Settings → Network & internet → Mobile hotspot ตั้ง Hotspot ให้เป็น 2.4 GHz แล้วให้จอต่อ Hotspot นั้นตามขั้นที่ 2
  • ขอฝ่าย IT: ขอให้อนุญาตอุปกรณ์นี้ (แจ้ง MAC address ของจอ) และเปิดให้คุยกับคอมได้ที่พอร์ต 8766
